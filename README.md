# NIVAS

NIVAS is a hostel onboarding and resident services platform designed to simplify the student journey from first-time authentication to hostel allocation and day-to-day support.

## Features

- OTP-based first-time authentication
- Student profile and personal details
- Document and undertaking submission
- Annual hostel fee payment with Razorpay
- Room selection
- Mess plan selection
- 30-cycle laundry plan and pickup requests
- Hostel Wi-Fi usage tracking
- Digital hostel pass
- Hostel issue and ticket management
- Medical and emergency assistance requests
- Hostel announcements
- Role-based access for Students, Admins, and Staff/Wardens

## User Roles

### Student

- Complete hostel onboarding
- Submit documents and undertaking
- Make annual fee payment
- Select room and bed
- Select mess plan
- Manage laundry requests
- Track Wi-Fi usage
- Raise tickets and assistance requests
- View hostel pass and announcements

### Admin

- Manage students and onboarding
- Verify documents and payments
- Manage rooms and beds
- Manage mess and laundry plans
- Publish announcements
- Manage tickets and assistance requests

### Staff / Warden

- View assigned students and rooms
- Handle tickets
- Process assistance requests
- Update request and resolution status
